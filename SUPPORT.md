# Support

Bastión VPN is an infrastructure project. Use the channel that matches the problem and redact operational data before sharing it.

| Need | Channel |
| --- | --- |
| Reproducible bug | [Bug report](.github/ISSUE_TEMPLATE/bug-report.yml) |
| Product or integration idea | [Feature request](.github/ISSUE_TEMPLATE/feature-request.yml) |
| Usage question | [Question form](.github/ISSUE_TEMPLATE/question.yml) |
| Security vulnerability | [Private security report](https://github.com/juanuto/plantas-vpn-bastion/security/advisories/new) |
| Immediate production incident | Your organization's incident process first; this repository is not a 24/7 operations desk. |

Before requesting help, collect only safe metadata: commit or image tag, engine type, non-sensitive plant slug, container state, health status, timestamp, and a redacted error category. Do not attach `.env`, VPN profiles, private keys, databases, cookies, encrypted payloads, or raw logs.
