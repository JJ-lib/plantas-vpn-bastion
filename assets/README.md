# Assets

All repository artwork is self-contained SVG. It is intentionally neutral: it documents the product model without embedding customer names, gateways, addresses, screenshots, or runtime state.

- `brand/` — logo, banner, favicon, and social preview.
- `diagrams/` — architecture and onboarding illustrations.
- `illustrations/` — neutral control-plane visual.
- `icons/` — small feature icons used by the README and future documentation.
