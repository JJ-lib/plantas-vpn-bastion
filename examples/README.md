# Examples

Examples are synthetic and safe to publish. They are not production overlays and must not be copied with real credentials without a security review.

- `synthetic-site/` documents the minimum shape of a generated site overlay.
- `../templates/` contains canonical templates for deployment-side generation.
- `tests/fixtures/` contains synthetic protocol/profile fixtures.

A future portable demo profile will include public images and a completely self-contained loopback target. Until then, use these files to understand structure rather than as a production deployment.
