# Guacamole server source

This directory contains the tracked Apache Guacamole server source used by the bastion.
Imported from local branch guac2118-safe at the current deployment baseline.

The RDP CLIPRDR file-download changes are in:
- src/protocols/rdp/channels/cliprdr.c
- src/protocols/rdp/channels/cliprdr.h

Preserve the Apache license and NOTICE files when distributing this source.
