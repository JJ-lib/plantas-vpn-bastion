# Contributing to Bastión VPN

The canonical contributor guide is [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md). Read it before opening an issue or pull request.

The short version:

1. Keep changes scoped and explain operational impact.
2. Never add live credentials, private VPN material, databases, logs, or customer topology.
3. Preserve generated site network namespaces and manual production promotion.
4. Run the focused checks documented in the contributor guide.
5. Include tests and documentation when behavior or operator workflow changes.
